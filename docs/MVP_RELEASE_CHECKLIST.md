# MVP Release Checklist

## R1 Day 1 checklist

- [ ] Scene `Assets/Scenes/DayOne.unity` opens cleanly.
- [ ] Player starts inside shelter.
- [ ] Radio, storage and filter checks work in order.
- [ ] Door unlocks after required checks.
- [ ] Player can reach near loot and far loot.
- [ ] Search interaction has duration and cancel.
- [ ] Time/exposure increase only outside.
- [ ] Player can return to shelter.
- [ ] Filter can be used to complete Day 1.
- [ ] End-of-day summary appears.
- [ ] Replay/reset works without restarting Editor.
- [ ] HUD is readable without debug-only language.
- [ ] Edit Mode tests pass.
- [ ] 5 human playtests recorded in `PLAYTEST_NOTES.md`.

## Build target

- Platform: Windows desktop.
- Engine: Unity 6.5 `6000.5.4f1`.
- Scene: `DayOne`.

## Controls

- Move: WASD or arrow keys.
- Interact: E.

## Not release blockers for R1

- Full shelter upgrade tree.
- Multi-day run.
- Storm phase.
- Inventory grid.
- Combat.
- Minimap.
